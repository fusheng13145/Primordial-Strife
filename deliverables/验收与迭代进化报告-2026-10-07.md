## 2. 本机实跑证据（非"声称绿"）

受 `docs/02 §4` 约束，platform 单测因仓库路径含非 ASCII 字符触发 Gradle #30304（测试 worker 启动即 `ClassNotFoundException`），**只能由 CI 执行**；但 `datagen` / `validator` 的 `run` 类任务不走测试 worker，本机可真跑。本次实测：

| 门禁 | 命令 | 结果 |
|---|---|---|
| 内容生成 | `./gradlew :tools:datagen:run` | `tables=17 rows=83 generators=12 numbers=5 products=46 problems=0` ✅ BUILD SUCCESSFUL (9s) |
| 内容校验 | `./gradlew validator` | `json-files=46 csv-files=17 checks=11 problems=0` ✅ BUILD SUCCESSFUL |
| Spotless | `:tools:datagen:spotlessCheck :tools:validator:spotlessCheck` | ✅ BUILD SUCCESSFUL |
| **W4 断链门禁（受控注入）** | 向 `dialog_trees` 注入 `give_item: ghost_item_xyz`（悬空引用） | 报 `item reference 'ghost_item_xyz' has no source-row... V-REF phase 2` → **problems=1 → BUILD FAILED** ✅ 移除后恢复绿 |

> 断链门禁另由 4 个既有回归测试固化（`dialogNpcReferenceMustHaveALoreCard` / `questTechniqueRewardMustExistInTheSourceTable` / `startQuestEffectMustReferenceAnExistingQuest` / `itemEffectPassesWhenLangCarriesTheItemKey`），与本次手动注入互为印证。
