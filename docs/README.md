## 快速上手（新成员 / 新 Agent）

1. 读 01 分册（10 分钟）——理解边界，知道什么不做。
2. 按 02 分册搭环境，跑到 `./gradlew :platform:runServer` 出日志。
3. 领任务前看 06 分册，确认目标目录属于哪个权限分区。
4. 提交前跑 `./gradlew spotlessCheck build test validator`（06 §4 交单命令），红了不许提。

**不写代码的成员（数值 / 剧情 / 文案）**：读完 01 后直接看 [tables/FILLING_GUIDE.md](../tables/FILLING_GUIDE.md)——它把字段契约翻译成人话，§0 说明了"现在填表还不会进游戏"的真实状态；要改数值去 `content/NUMBERS.md`，要改设定去 `content/LORE.md`。逐系统的玩法施工说明在 [附录 EP0 功能设计草案](appendix/EP0功能设计草案.md)。

## 术语表

| 术语 | 含义 |
|---|---|
| 修为（QiExp） | 打坐/丹药/任务获得的成长值，决定突破进度 |
| 灵气（Mana） | 施法/功法消耗的资源 |
| 寿元（Lifespan） | 境界提升增长的寿命上限，耗尽触发"大限"结算 |
| 灵气浓度（AmbientQi） | 区域环境灵气，构成修炼速率的环境系数 |
| 品质阶（凡/地/天/仙） | 物品/灵根/产物的统一品质分级口径 |
| 灵石 | 统一货币单位（H1 价格字段以其计价），亦是布阵/修炼能源 |
| 大限 | 寿元耗尽触发的非破坏性惩罚结算（05 §4，D6） |
| MVP | 主链可玩最小闭环 = M0–M3 准出物（灵根→修炼→突破→序章任务链） |
| W4 演练 | 固定动作代号（与周编号无关）：断链校验于 M3 末、3 天产一章产能演练于 M4（07 §6） |
| EP0–EP4 | 资料片代号：EP0 本体 / EP1 风起坊市 / EP2 秘境纪元 / EP3 万族棋局 / EP4 飞升之后（09 分册） |
| content-base | 纯数据资源层（JSON/lang/贴图），可独立替换更新 |
| 纯净 jar | 剔除 client-fx、可在专用服务端独立启动的发布物 |
| 权限分区 | 06 分册定义的 禁区/灰区/开区，约束 Agent 可改范围 |
