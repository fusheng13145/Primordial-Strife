# 09 世界完整度图谱（Compendium）

> **本分册是地图，不是待办。** 收录一个"真实完整的修仙世界"应有的全部构成域（调研自《凡人修仙传》《遮天》《完美世界》《一念永恒》《剑来》等代表作及通用设定），用途仅三个：① 排期时判断某想法属于哪个域、归哪个资料片；② 校验 03 分册 §10 七钩子是否够用；③ 阻止"图谱外的临时发明"。任何条目要开工，必须走 ADR + 准出条件，与新增系统同等对待。
>
> **版权红线（05 §7）**：本分册与附录调研报告中的网文专名/情节仅限内部调研用语，一律不得进入游戏内文本与资产命名。
>
> 资料片代号：EP0 本体（M0–M6，已定主链）；EP1 风起坊市（经济与社会）；EP2 秘境纪元（机缘与冒险）；EP3 万族棋局（势力与战争）；EP4 飞升之后（上界与终局）。可行性 = 用"数据驱动 + MC 现有机制"表达的难易。

## 钩子自检

上表所有"中/高 + EP≥1"条目，均可由 H1–H7（03 §10）+ 现有 quest/对话 DSL + 内容管线承载，**不需要新的平台层重构**——这是图谱成立的检验标准；未来若某条目需要新钩子，走 ADR。**战争类条目（人妖大战/外敌入侵/宗门战争）的实现必须走 H7 声明式定义**：同一场战争是"一次性主线"还是"周期活动"只改表不改码（ADR-016 变形测试）。
