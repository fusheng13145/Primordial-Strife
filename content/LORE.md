## 1. 世界总纲

**一句话**：玄黄之世，万族争劫——天道不设裁判，只提供寿命与雷劫；所有势力都在"劫"字上押注。（05 §6 主题基调 `[锚]`）

- 世界层级：本期只交付**人界**一层。灵界/仙界属 EP4，靠 H4 位面钩子接入，本文件先定称呼与禁忌（§6.5）。
- 时间观：世界有"纪元"概念（成住坏空的长周期），但**单机只做成背景与周期 modifier**（09 G `[锚]`）。玩家能感知的是 H5 时钟给出的窗口事件（灵脉潮汐、秘境开启），不是历法模拟。
- 玩家的位置：一个凡人出身的散修苗子，寿元有限、天赋随机（灵根由服务端生成一次，03 §8）。**没有天选设定**——世界大势不为玩家而转，玩家的成长改变的是自己在洪流中的位置（05 §6"个人求道与世界洪流的相互作用"`[锚]`）。
- 边界 `[锚]`（01 §5）：不做玩家间经济、不做 PvP 平衡体系、不做 MMO 化；势力对抗是被模拟的世界内容，不是竞技场。

### 2.1 五行与灵根（`[拟]`，需 C 确认后成为全项目统一口径）

五行取**金 / 木 / 水 / 火 / 土**，与内容 ID 词表一致：`jin / mu / shui / huo / tu`（JSON_SCHEMA §1.4），位序 bit0..bit4 与 `StrifeData.spiritroot_elements` 一致。

- 相生：金生水、水生木、木生火、火生土、土生金。
- 相克：金克木、木克土、土克水、水克火、火克金。
- 与玩法的映射（NUMBERS §6 三档亲和）：**同属性 = `matched`（1.25）**；**相生且功法属性为玩家灵根所生 = `neutral`（1.00）**；**相克 = `conflict`（0.60）**，其余组合 `neutral`。相克不禁止修炼，只是慢——面板必须给出 tooltip 解释（05 §2"任一系数为 0 必须有解释"的同一条纪律）。
- 品阶：单一金行灵根最贵（`quality_tier_1`），五行俱全最杂（`quality_tier_4`），权重与系数查 NUMBERS §6。`[拟]` 术语：天灵根（单）／双灵根／三灵根／杂灵根（四五）。变异灵根（雷/冰）属 EP2，本期不命名。
- **永不重算**：灵根在服务端首次进服生成一次并入档（03 §8）；洗髓道具重置后，不满足 `required_spiritroot` 的已学功法置灰并写明 `disabled_by` 原因，禁止静默失效。

## 3. 修炼体系用词（写作时的统一口径）

| 统一用词 | 禁用的写法 | 说明 |
|---|---|---|
| 修为 | 经验值、EXP、进度 | 只有"修为"这一种说法；`qi` 是实现字段名，不进文本 |
| 打坐 / 闭关 | 挂机、泡怪 | 打坐 = 玩家主动动作；`offline_gain_allowed: false`（NUMBERS §5），所以**不存在"挂机得修为"** |

| 大限 | 死亡、删号 | 寿元耗尽的结算事件名，绝不用于威胁玩家账号 |
| 灵根 | 天赋值、资质点 | 五行 + 品阶，服务端签发 |
| 功法 / 法术 | 技能书 / 技能 | 功法是修炼路线（有前置、有倍率），法术是战斗表达 |
