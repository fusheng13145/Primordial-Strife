# P1-18 2h 连续运行 · 手工执行手册（2026-11-01）

> **为什么是手册**：自动化尝试三连败于环境（①bat 内中文路径被 cmd 代码页毁掉；②隐藏窗口里 `timeout` 因无控制台失效，13 采样瞬间跑完；③subst 盘符下 `tools/datagen` 的 repoRoot 相对解析失败）——每处都已定位并记录在案。**2h 窗口本身只需要一个交互终端**，步骤如下（约 5 分钟人工 + 2 小时挂机）。

## 步骤

1. 开一个**交互** cmd/PowerShell（不要用计划任务/Start-Process 隐藏窗口）：
   ```
   cd /d <仓库>\mod
   gradle :platform:runServer --offline
   ```
   等 `Done (…s)!` 与 `RCON running on 0.0.0.0:25575`。
2. 另开终端，每 10 分钟采样一次（共 13 次）：
   ```powershell
   Get-Process java | Where-Object { $_.MainWindowTitle -eq '' } | Measure-Object WorkingSet64 -Sum
   ```
   （或 `jcmd <pid> GC.heap_info`）记入下表；顺手跑一次 `python rcon.py "strife world ore status"` 保持 RCON 探针。
3. 2 小时后 `stop`；核对：日志 0 `ERROR/Exception`、RSS 首尾差 <200MB、无崩溃。
4. 回填 `发布检查单-0.0.1.md` 的 P1-18 行与本表。
