# 安装说明 — strife 0.1.0（草案）

> **状态**：草案，P1 准出未签、本人实机批未做，**不是已发布版本**。本文件服务 P1-19「安装说明」证据；版本号与三制品归档仍待本人裁决（现存 `deliverables/artifacts/` 为 0.0.1）。
>
> 权威口径：`docs/02 §4`（技术基线）。本文与之冲突时以手册为准。

## 1. 环境要求

| 项 | 值 | 说明 |
|---|---|---|
| Minecraft | **1.21.1** | 其他版本不加载 |
| 加载器 | **NeoForge 21.1.251+** | 必须是 **NeoForge**，不是 Forge；PCL2/HMCL 在"版本"里选 NeoForge |
| Java | **21** | 服务端与客户端一致 |
| 内存 | 建议 2 GB+ | 与同规模整合包一致 |
| 网络 | 首次启动可离线 | 登录超时（`authlib ... Read timed out`）不影响载入 |

## 2. 制品

| 制品 | 给谁 | 放哪 |
|---|---|---|
| `strife-<版本>.jar` | 客户端 / 单机 / 联机客户端 | 实例 `mods/` |
| `strife-server-<版本>.jar` | 专用服务端 | 服务端 `mods/`（已剔除 `com/strife/clientfx/**`） |
| `content-base-<版本>.zip` | 整合包作者 / 热更内容 | 解包覆盖到实例的 `data/` 与 `assets/`（普通玩家不需要） |

> 制品名中的 `<版本>` 以实际构建为准。仓库当前 `gradle.properties` 的 `mod_version=0.0.1`，0.1.0 的版本号变更与三制品归档属发布决策，需本人确认后执行。

## 3. 客户端安装（单机 / 联机）

1. 用 PCL2 / HMCL / 官方启动器新建 **NeoForge 1.21.1** 实例（版本号 ≥ 21.1.251）。
2. 把 `strife-<版本>.jar` 放进实例的 `mods/` 目录。
3. 启动游戏。**载入判据**（三条都出现才算成功）：
   - MOD 列表出现 `Primordial Strife <版本> (strife)`；
   - 日志出现 `strife platform entry constructed` 与 `strife clientfx entry constructed`；
   - 日志出现 `ResourceManager: ... mod/strife ...`。
4. 进世界后左下角应出现修仙 HUD（`境界 凡人 · 修为 0`）。

**装错加载器（Forge）或版本不对（非 1.21.1）时，MOD 不会出现在列表里**——先核对这两项，再查日志。

## 4. 专用服务端安装

1. 安装 NeoForge 1.21.1 服务端（≥ 21.1.251），首次启动生成 `eula.txt` 并同意。
2. 把 `strife-server-<版本>.jar` 放进服务端 `mods/`。
3. 启动，看到 `Done (...)!` 即开服成功。客户端连接同一服务端时，客户端也需装主 jar。

## 5. 整合包作者（内容热更）

`content-base-<版本>.zip` 内是 `data/` 与 `assets/` 的生成产物（任务、对话、配方、世界生成、lang 等）。解包覆盖到实例根目录即可替换内容，不需要重新构建 jar；**源表与产物的一致性由构建期 Validator 保证**，手工改产物会破坏 `@generated` 哈希（V-FRESH 会红）。

## 6. 首次进游戏自检（建议）

```
/strife info                      玩家数据（境界/修为/寿元/灵根）
/strife world ore status          矿石链四类缺口应全 [OK]
/strife quest status              任务进度（序章十节点）
/strife guide                     入门指引
```

任务追踪条在屏幕顶部（BossBar）；`/strife quest track off` 可收起。序章 #1 需要与石执事**真实对话**完成，登录不代推；找不到 NPC 时用 `/strife world place goto qi_luoxia` 前往落霞山麓，或 `/strife npc spawn <npc_id>` 补位。
