# 附录：修仙世界体系调研报告

> ADR-013 附件，09 分册的来源依据。调研时间 2026-09-19，由 AI 网络调研产出、C 与组长复核后生效。调研对象：《凡人修仙传》《遮天》《完美世界》《一念永恒》《剑来》及通用修仙设定。

## 一、世界体系全景清单（约 70 项）

**A. 修炼体系**：境界阶梯（练气→…→渡劫飞升，业界通用语）；灵根/体质（五行/变异/天灵根、混沌体、荒古圣体）；寿元驱动（凡人核心张力）；神识/神魂（第二资源：探查/夺舍/御器）；功法品阶与传承链（黄玄地天阶、残卷、禁制、师传）；道意/法则领悟（剑意、五行真意、时间法则）；顿悟与闭关（时间跳变成长）；心魔/魔染（突破失败分支）；双修/炉鼎（争议项，本项目不做）；夺舍/转世/分身。

**B. 资源与经济**：灵石（下/中/上品+极品，1:100，货币兼能源）；灵田灵脉（不可再生资源→战争动机）；丹药/法器/材料；坊市（中立区/摊位费/蒙面/鉴定阁/坊主禁令）；拍卖行（保证金/暗拍/压轴/拍后追杀定式）；黑市销赃；借贷与因果债（培养资源绑定、叛逃缉拿）。

**C. 战斗**：法器→法宝→灵宝→仙器分级与本命温养；飞剑御物、遁光（速度=战力维度）；神通（法天象地、一气化三清）；阵法实战（困/杀/护山大阵）；符箓（一次性资源）；傀儡/身外化身；越阶战斗与保命底牌（韩立逻辑）；妖兽等级（一阶~十阶/妖王/妖圣）与妖丹经济。

**D. 势力与社会**：宗门职级（杂役→外门→内门→真传→长老→太上）、贡献点、任务堂、藏经阁分层、丹房配额、禁地、掌门 succession；世家（血缘灵根垄断、联姻）；散修联盟/雇佣供奉/情报贩子；正魔结构（秩序 vs 掠夺两种组织哲学）；妖族（血脉/化形/妖丹，"另一套文明"）；魔族/域外天魔、鬼修；凡俗王朝（纳贡-庇护；低魔遮蔽 vs 高魔分支）；宗门战争（灵脉/秘境份额/大阵攻防/俘虏赎金）。

**E. 天地规则**：灵气浓度场；天劫（可被干扰/借阵削弱/兵解散仙）；飞升（界面升迁+力量剥夺=资料片切换器）；天道（规则型 vs 意志型、"天道有缺"）；纪元与量劫（成住坏空、黄金大世/末法时代）；天人五衰；世界壁垒；因果；气运。

**F. 机缘冒险**：秘境/小世界（定期开启、限境界；遮天"小世界为强者私产"）；上古遗迹与传承考验（资质/心性/气运三轴）；天才地宝（宝出异象→抢夺→收割链）；天骄榜/百族大战/诸子论道；追杀与流亡；寻宝/鉴宝金手指；海域荒域探索；混沌险地。

**G. 社会生活与百艺**：炼丹（火候/丹劫/废丹）；炼器（器胚/禁制数/器灵）；符箓；阵法（阵盘/阵眼/破阵）；灵植（轮作/催熟代价）；御兽（契约/血脉提纯/兽丹）；傀儡；星象占卜（事件预告）；鉴宝当铺；医术毒术；灵厨酿酒；建筑营造（洞府/山门）；舟车交通；酒楼茶肆情报；凡俗城镇；婚配道侣；师徒荫庇；葬地风水。

**H. 宇宙观**：人界→灵界→仙界→混沌（凡人三层最完整）；三千道州/诸天万界；星空古路与跨界传送（遮天）；四座天下/他方世界与信仰体系（剑来）；神道/敕封与修士共存（城隍、山岳正神）；轮回与彼岸。

## 二、经济与社会重点（《凡人修仙传》）

- 价格锚点示例：中型功法数百灵石、法宝数千——通胀层级本身就是境界追求曲线。
- 坊市本质是"中立服务区+抽成经济体"，大型坊市本身即势力，规格随地图升级（黄枫谷坊市→天南诸坊→大晋坊市群）。
- 拍卖会 = 稀有物资产出 + 价格发现 + "必出大事"叙事钩三合一。
- 宗门本质是"军事化资源企业"（社区精辟总结，见来源），散修是其临时劳动力与消耗品——这条关系模型值得直接移植。
- 资源地理学：灵脉/灵矿不可再生 → 一切宗门战争的底层动机模型。

## 三、成长与机缘重点

- 秘境四形态：定期开启试炼型 / 破碎遗迹夺宝型 / 掌中洞天私产型 / 小世界容器型。
- 传承考验三轴（资质/心性/气运）可直接映射为"副本 + 结算 + 掉落"。
- 气运是全局隐藏数值：影响掉落与事件概率，"气运之子不可轻杀"（反噬）是规则化范例。
- 顿悟/立道（剑来本命字、拳意）哲学层厚重——本项目以文本+被动表承载为宜。

## 四、势力组织重点

一念永恒"香堂/药园技术兵种编制"证明宗门职能部门可玩法化；剑来"多道并立"（儒释道兵神）提示修炼体系不必唯一，多"道"并立极大增加世界厚度。

## 五、可落地性分级结论

- **高**（数据驱动直接表达）：境界/功法/丹方/器图、灵根、寿元闭关、灵石+坊市+拍卖、悬赏任务、秘境（维度/结构）、百艺、妖兽等级、符箓、阵法、宗门职级贡献、天骄榜、天雷渡劫。
- **中**（需专门系统但可行）：神识、灵脉场、气运福缘、心魔、因果追踪、势力战争（简化）、御兽傀儡、占卜、夺舍分身。
- **低**（文本承载）：纪元量劫全局史、道意哲学层、繁复宇宙观细节、双修（不做）。
- **六个高杠杆钩子**（ADR-012 由此产生；后 ADR-016 增补 H7 势力关系图+战争状态机，现行共 7 个，见 03 §10）：价格字段、声望向量、因果-flag 图、位面迁移协议、全局时钟纪元、luck modifier。

结论：**凡人的"资源-经济-生存"骨架 + 遮天/完美的"境界-秘境-天骄"骨架 + 剑来的"多道并立与神道社会"骨架**，钩子齐备则扩展空间足够 3–4 个资料片。
